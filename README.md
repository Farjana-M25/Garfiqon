# Graficon Website

A responsive, GitHub Pages-ready static website concept for **Graficon — Printing Solutions Beyond Borders**.

## Files

- `index.html` — page structure/content
- `styles.css` — responsive visual design
- `script.js` — mobile menu, scroll reveal, demo enquiry form
- `assets/company-logo.jpg` — supplied Graficon logo

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public site URL.

## Before launch

Replace the placeholder contact information in `index.html`:

- `YOUR-EMAIL@DOMAIN.COM`
- `+880 XXX XXX XXXX`
- `Your office / city`

The quote form currently demonstrates the UI only. For real submissions, connect it to a form service or backend.

## Easy customization

The primary brand colors are defined at the top of `styles.css`:

- `--navy`
- `--blue`
- `--cyan`

The service cards and page copy are also intentionally easy to edit in `index.html`.
